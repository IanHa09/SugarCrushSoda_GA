# 전체 CLI 모음

# 전체 옵션 확인
.venv/bin/python candy_soda_agent/main.py --help

# 플레이
.venv/bin/python candy_soda_agent/main.py --once
.venv/bin/python candy_soda_agent/main.py --auto

# 구조 조사
.venv/bin/python candy_soda_agent/main.py --survey-once
.venv/bin/python candy_soda_agent/main.py --autodrive --survey-taps
.venv/bin/python candy_soda_agent/main.py --autodrive --survey-taps --autodrive-steps 20

# Autodrive 호환 별칭
.venv/bin/python candy_soda_agent/main.py --survey-auto --survey-taps
.venv/bin/python candy_soda_agent/main.py --survey-auto --survey-taps --autodrive-steps 20

# 보고서 재생성
.venv/bin/python candy_soda_agent/main.py --survey-report

# 단축키 모드
.venv/bin/python candy_soda_agent/main.py --hotkeys

--autodrive와 --survey-auto는 같은 모드라 동시에 사용할 수 없습니다. 
Autodrive는 --once, --auto, --survey-once, --survey-report, --hotkeys와도 함께 사용할 수 없습니다.

output/captures/
- 실제로 분석한 화면을 단계별 증거로 저장
- 같은 화면도 요청마다 별도 저장될 수 있음

output/navigation/representatives/
- 화면 노드별 대표 이미지 보관
- 구조도 표시용
- 분석 입력으로 다시 사용하지 않음
